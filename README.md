# Калькулятор на C++

Простой консольный калькулятор с русскоязычным интерфейсом.

## Возможности

- сложение;
- вычитание;
- умножение;
- деление;
- защита от деления на ноль;
- проверка корректности введённых чисел;
- поддержка UTF-8 в консоли Windows.

## Требования

- компилятор с поддержкой C++17, например GCC/MinGW-w64;
- Windows, Linux или macOS.

## Сборка

В PowerShell перейдите в папку с проектом и выполните:

```powershell
g++ calculator.cpp -std=c++17 -Wall -Wextra -pedantic -o calculator.exe # Компилирует исходный код и создаёт исполняемый файл.
```

## Запуск в Windows

```powershell
chcp 65001 # Переключает текущую консоль Windows на кодировку UTF-8.
.\calculator.exe # Запускает собранный калькулятор.
```

## Запуск в Linux или macOS

```bash
g++ calculator.cpp -std=c++17 -Wall -Wextra -pedantic -o calculator # Компилирует исходный код и создаёт исполняемый файл.
./calculator # Запускает собранный калькулятор.
```

## Использование

1. Введите первое число.
2. Выберите одну из операций: `+`, `-`, `*` или `/`.
3. Введите второе число.
4. Получите результат и выберите, нужно ли продолжить вычисления.

Исходный код снабжён комментариями, которые объясняют назначение каждой строки.
